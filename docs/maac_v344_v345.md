## 3. 观测、Replay 与死亡处理

Actor 可处理 `[4,49]` 或 `[B,4,49]` 输入并输出 `[4,3]` / `[B,4,3]`。同一 Actor 参数供全部 Red 使用。Critic 使用联合观测和动作，输出 `[B,4,1]`；注意力为 `[B,4,4,4]`，自注意力和死亡智能体对应行列屏蔽。

JointReplayBuffer 由配置实例化为 `[B,4,49]`，保存动作、奖励、真实 transition_next_observations、回合终止及前后 alive mask；跨自动重置时保留终止观测。专项测试跨两个完整回合采样。正式参数审计每版实际收集 12 个完整回合，并在 Replay 中验证终止样本及死亡 mask。

原 TD 公式保持不变：回合终止或 next_alive=0 时 Bootstrap 为零，目标等于即时奖励。测试实际验证该等式，死亡 Actor 动作为零、Critic 输出和注意力被屏蔽，输入、目标、基线、梯度和优化器状态有限。

## 4. 训练与评估事件语义

新版本均标记 `event_semantics=continuous_dwell_neutralization`、`legacy_fire_metrics_applicable=false`。MAAC 的 `fire_rate=null`，控制台标记 N/A；环境旧 fire_attempts / weapon_hits 保持 0 占位，不能用于推断是否接敌。旧版本 fire_rate 仍是发生过 Red 开火尝试的回合比例，kill_rate 仍表示发生过 Red 实际击毁的回合比例。

| 指标 | 精确定义 |
|---|---|
| `red/blue_dwell_geometry_episode_rate` | 至少存在一次合法几何区域配对的回合比例 |
| `red/blue_dwell_start_episode_rate` | 至少开始一次驻留段的回合比例 |
| `red/blue_dwell_complete_episode_rate` | 至少完成一次驻留段的回合比例 |
| `dwell_start_episode_rate` / `dwell_complete_episode_rate` | 上述 Red 回合比例的无前缀别名 |
| `red/blue_dwell_started` | 每回合开始驻留段数量的平均值 |
| `red/blue_dwell_completed` | 每回合完成驻留的攻击方智能体事件数平均值 |
| `red/blue_dwell_neutralizations` | 每回合去重目标失效数平均值，与 attack_kills 相等 |
| `red/blue_step_dwell_completed` | 自上次写日志以来所有采样 transition 的完成事件总数 |
| `red/blue_step_attack_kills` | 同一 transition 区间内唯一目标失效总数 |
| `mutual_annihilation_draw_rate` | 全部回合中 draw=true 且 Red、Blue 均 0 存活的比例 |
| `red_win_rate` / `blue_win_rate` / `draw_rate` | 胜、负、平局的回合比例 |
| `red_survivors` / `blue_survivors` | 回合终止时存活数量平均值 |
| `average_red_loss` / `average_blue_loss` | 回合损失数量平均值 |
| `mean_episode_return` | Red 四个智能体累计回报之和的回合平均值 |
| `average_episode_r1_total` 至 `r4_total` | 原 Reward 分量累计值的回合平均值 |

训练回合指标对最近 recent_episode_window 个**已完成**回合等权聚合；还没有完整回合时使用 null。步指标统计自上次写日志以来的 transition，不把累计的回合计数反复相加。训练与评估共用 `aggregate_combat_records` 和 MAAC 别名适配，并分别写出统计范围说明。

几何进入不等于 Blue 已选定该目标，开始不等于完成，完成数不等于唯一目标失效数。自动测试构造四架 Red 同时完成同一 Blue 的驻留，确认 completed=4、neutralizations=1、attack_kills=1，旧 fire_attempts / weapon_hits=0；也验证完整互毁时双方全灭平局率。实际 v3.45 录像同样出现 Red completed=5 而唯一失效=4，Blue completed=3 而唯一失效=2。
