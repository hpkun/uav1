# Combat Environment v3.41：武器命中距离归一化重标定

## 目的、结论与版本边界

以v3.40为基线，只把weapon.effective_hit_distance从1000/ln(6)=558.1106265512473 m改为2000/ln(6)=1116.2212531024945 m，并使用独立环境身份3.41。其余环境有效参数与MAPPO配置完全冻结。

2000/ln(6)来自项目历史v3.35的“命中距离尺度随武器最大射程归一化”标定原则，不是论文明确给出的数值。新版本在最大射程2000 m处恢复正对目标约40%的理论命中概率。

预检表明：远射命中性能确实提升，射击次数和未命中消耗减少；与此同时首次交战更致命、回合缩短，R4仍没有曝光。故不能把命中率改善等同于更好的战术学习环境或训练后性能。没有技术阻断，允许作为受控实验候选进入后续3M，但不据此优先认定v3.41更好。本轮没有执行正式3M训练或额外调参。

## 理论概率与归一化

原命中判定不变：T(d)=pi*exp(-d/Dhit)，同一个epsilon~N(0,1)同时进入ATA与HA。独立解析核对取两个允许epsilon区间的交集，再计算标准正态CDF差；不是两项独立概率相乘，也不是三维攻击锥。

| 距离/m | v3.40正对概率 | v3.41正对概率 |
| --- | --- | --- |
| 500 | 80.10% | 95.56% |
| 1000 | 40.00% | 80.10% |
| 1500 | 16.95% | 58.82% |
| 2000 | 6.96% | 40.00% |

2km处不同角度组合如下；完整4距离×5角度×2版本矩阵见probability_audit.csv。

| ATA/HA | v3.40概率 | v3.41概率 |
| --- | --- | --- |
| +0°/+0° | 6.96% | 40.00% |
| +15°/+15° | 6.73% | 38.77% |
| +30°/+30° | 6.07% | 35.29% |
| +15°/-15° | 0.00% | 20.68% |
| +30°/-30° | 0.00% | 0.00% |

验证P_v340(d,ATA,HA)=P_v341(2d,ATA,HA)，并以历史v3.39为参考验证相同归一化射程r下P_v339(1000r)=P_v341(2000r)，对应阈值相同。覆盖r=.25/.5/.75/1及额外外推点、全部五种角度组合，共30组。v3.40与v3.41同为2km射程，但v3.40保留旧尺度，因此相同物理射程比例下的概率本来就不同。超射程函数值只是数学诊断，不能解释为合法开火。

实际attempt_hit逐次蒙特卡洛：40组、每组200000次，共8000000次；最大绝对误差0.00179961（0.1800个百分点），最大标准误差倍数1.733。各组满足6倍标准误差+2/n容差，该容差是数值验证规则，不是对局性能显著性检验。独立解析与函数差异<1e-15。

Spy逐步检查10000次调用，每次恰好一个标量normal，两个版本每步RNG状态一致；3651次命中布尔结果不同，符合概率改变的设计。不同对局在命中后改变存活、目标集及后续RNG消耗，同seed只配对初始化。

## 科研解释与是否进入3M

理论概率、条件开火命中率、唯一击毁数和训练后性能必须区分。数据支持有效远射命中提高，远射未命中数和弹药消耗减少；也支持首次交战更早致命、回合变短。两种作用同时存在，不能回答为单一的“只改善”或“只过早击毁”。红方固定策略胜率并非统一改善：zero 35%→30%，pursuit 55%→35%，lateral 0→0，vertical 25%→40%。本轮没有训练后性能结论，也未做总体显著性或多seed训练稳定性推断。

从技术验收看，可以启动独立v3.41 MAPPO 3M受控训练，无新增阻断；从研究选择看，只建议把它作为与v3.40公平比较的候选，不建议认定它已经解决R4稀疏或作为更优默认。若目标是增加尾后战术学习机会，本次固定策略证据尚不支持；需在后续正式训练中继续观察。未降低命中率、增加弹药、改蓝方或改奖励来改善指标。本轮到此停止，不自动启动3M。
