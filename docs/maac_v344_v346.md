# MAAC v3.44 / v3.46

两个版本均使用现有 MAAC：共享高斯 Actor、单 Attention Critic、Joint Replay、反事实 Monte Carlo 基线和原更新公式。正式配置仅环境身份不同：`configs/maac_4v4_v344.yaml` 与 `configs/maac_4v4_v346.yaml`。

维度均为 49/3/4；hidden=128、heads=4、12 个环境、minibatch=1024、replay=1,000,000、baseline_samples=16。全部学习率、更新间隔、alpha、tau、gamma 与 v3.44 一致。`trainer.py`、`networks.py`、`replay.py` 无改动。PBRS gamma 必须等于训练 gamma。

`algorithm/maac/protocol.py` 注册两个独立身份，Checkpoint 验证包含环境版本、环境与算法配置 SHA256、网络结构和实现版本；相同维度不能绕过身份。v3.45 已退役，拒绝作为可训练环境，历史 Checkpoint 不可转成新版本。既有 MAAC 不支持精确恢复训练，因为 Replay/完整环境状态未保存，本次保留该边界；确定性评估重载仍支持。

驻留日志沿用 `continuous_dwell_neutralization`，fire_rate=None，完成段数和唯一目标失效分开。评估、训练指标和录像均沿用原通用入口。R4 的进攻/防御诊断记录实际应用的贡献；进攻优先时防御贡献为零，避免错误相加。

`tests/test_maac_v344_v346.py` 保留 v3.44 和旧版本覆盖，补入 v3.46。`tools/verify_maac_v344_v346.py` 保留 v3.44/新版本有界诊断能力；本次正式参数 CUDA 验收由 `tools/verify_v346_readiness.py` 调用其中 `formal_update('346', ...)`，不使用小网络 Smoke 代替正式参数验收。

完整奖励、验证结果、风险和三个算法命令见 [v3.46 交付说明](combat_environment_v346.md)。
