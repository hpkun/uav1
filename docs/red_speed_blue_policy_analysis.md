## 2. 数据口径与可信度

16个主要/端点checkpoint共1600局，2,155,904个存活Red agent-step。原trace、metadata和事件完整保留，未重新构造回放框架。

样本在transition前的frame t存活时纳入：v来自frame t，a_v来自实际执行transition t，Δv=v[t+1]−v[t]。死亡当步保留，后续冻结尸体状态剔除。总体统计为存活飞机时间加权，另保存每局等权统计；不能将数百万相关step当作独立episode。

最近存活Blue仅为Red几何诊断，不代表Red网络的目标意图。Blue追击目标直接来自info的canonical记录，不按距离重建。ATA/HA/AA唯一来源是engagement_geometry；heading error=|ATA|。HA不减pitch，另列的elevation_error才是相对pitch误差。

fire/threat window是几何窗口，不含ammo/cooldown/re-entry；armed列另加ammo。实际fire/hit/kill只取事件。所有存活Blue速度均核验为225m/s；Red速度映射残差最大为0.0m/s。

## 13. 合理战术与简化环境依赖

明确观察到速度维被持续使用：没有自然掉速，负a_v足以解释225向低速变化。但多数策略长期负动作并驻留下限，不能称为已经学会精细或最优速度管理。近距慢于远距跨policy一致；通用大角度转弯进一步减速则不一致：MAAC三个seed明显为负，但MAPPO/EA/EAA有反向情况。只吸收前者的温和版本，不把后者强塞给Blue。
胜局与败局平均速度相差通常很小；EA-MAPPO池化胜/负均约161m/s。其seed3 best和完成端点也都约160m/s，胜率却为67%与39%，证明低速本身不足以解释成功。火后/kill后多数观测仍接近下限，未见跨seed一致的高速脱离；少数seed有数m/s回升，不应扩展成通用加速状态。
低速在相同yaw rate下缩小转弯半径是几何事实；当前yaw rate不因低速下降且没有能量/失速代价，因此长期150m/s贴下限尤其依赖简化模型。低速胜局可说明有效，不等于真实航空合理性。火后没有稳定加速信号时，不能臆造“射后加速脱离”规则；远距没有稳定高速信号时也不增加高速追击档。

继续固定225m/s。全部Red正式初始化也是225，所有checkpoint的100个初始状态已核验一致；没有证据支持单方面给Blue宽速度随机化，本次也不推荐U(215,235)。

## 15. 推荐的简单Blue目标速度（仅方案）

V_near=210，V_chase=225，V_cruise=225 m/s。V_turn不另设降速档：非近距默认225，近距仍由V_near优先。可记V_turn(default)=225；实际只有两档。这样将研究变量限定为近距调速，不加入统计不一致的转向分支。

```text
d = distance to current nearest-target pursuit target
if d <= 1000 m:     desired_speed = 210
else:                desired_speed = 225
a_v = clip((desired_speed - own_speed) / 2.5, -1, 1)
```

只使用当前追击目标距离和自身速度；heading error不进入推荐规则。最近目标选择与立即切换不变。不读取Red网络、reward、未来状态、pitch、AA、隐状态或额外随机数。V_chase=V_cruise，所以不增加冗余远距分支，不发明额外加速度模型。

## 16. 数值与阈值的证据、校准性质

12个best逐policy胜局条件中位数，再跨policy取中位数：大误差参考速度150.00m/s、近距参考速度150.00m/s。每policy等权，避免某个长episode或高采样seed支配设计。
不直接模仿Red极端值：near取225+(参考−225)/5后按5m/s取整并限制到[210,225]，得到210。收缩系数、保守下界和取整是明确的PROJECT DESIGN，不是论文参数，也不是数据识别出的唯一最优值。
distance threshold=1000m：这里已经进入各算法一致的低速平台，且与fire事件的低速一致，也是现有weapon作用尺度；刻意晚于部分Red的减速起点，避免复制整段150m/s接敌行为。heading threshold不启用；60deg仅是诊断分界，因为episode内对照不支持跨算法统一的转向减速。3km只用于统计，没有新增Blue战术状态。

## 17. 为什么保守、仍有哪些未知

保持初始225，不提高巡航/远追速度，不使用150/300极限；只有一个近距条件，没有独立转弯档、锁定、lead、能量模型、随机状态机或网络。近距档仅比原225降低15m/s，仍明显快于Red常用150。
不能保证Blue不会增强：降低overshoot和转弯半径本身可能提高其效果，也可能降低追击/closure。这里只给复杂度和幅度受限的候选，不报告未做的Blue胜率结果。

## 18. 与当前225的预期差异

1km之外保持原225，近距尝试适度降低closure和穿越风险；不针对大角度转向额外优化。期望减少完全固定速度的可利用性，但也可能降低追击效果。上述是待验证预期，不是本审计测得的效果。不承诺能量意义上的改进，不增加爬升/俯冲速度耦合。
